月面拾光 Android 1.0.2 / versionCode 3 测试记录
设备测试日期：2026-10-18～19

真机：OPPO PEMM20，Android 13，720×1600。
这是单台设备验证；尚未覆盖其他厂商、Android 7～12/14+、平板或各种异形屏。

通过的项目
- release APK 安装、同签名从 1.0.0 覆盖到 1.0.1、1.0.2。
- 非零测试纪录与设置在覆盖安装后保持一致。
- 默认全屏菜单、开始航行、拖动/摇杆/方向键；真实 Android 多指事件同时移动、加速、切相。
- 系统返回键暂停；后台停留后不自动继续，继续航行有恢复保护。
- 横竖屏切换、画布尺寸和设置面板边界检查。
- 冷启动与 Activity 重建后的本地纪录、音效偏好读取。
- Android 系统文件选择器导出 JSON、再次选择导入、确认后重启并恢复纪录。
- APK 无 INTERNET 和通用存储权限；所有资源随包提供，逐文件比对与 mobile/www 一致。
- APK v2 签名验证通过；证书为固定项目签名，支持后续覆盖更新。

持续运行
- 1.0.0 在同一手机上完成 5 分钟实际渲染和自动移动测试；之后版本未改动游戏渲染逻辑。
- 采样帧率 59～60 FPS，renderTier 0；不是逐帧性能分析，也不代表所有场景最低帧率。
- USB 充电测试条件下，电池温度约 35.1→35.4→34.7 ℃；进程内存采样约 185～227 MB。
- 只验证短时稳定性，不能据此断言长时间游玩不发热或其他手机同样流畅。

修复与复测
- 原生界面压力提示与分数区域重叠：调整全屏 HUD 布局。
- 快速后台切换的保护：Java onPause/onResume 与 Capacitor 生命周期事件共同保证暂停。
- 一轮后台测试被 OPPO 的测试辅助程序跨应用打开提示拦截；允许后重新执行通过。
- 最终 1.0.2 多指/后台/冷启动测试通过；旋转、覆盖安装快照与文件往返测试通过。

本地检查
- tests/game.cjs：现有游戏回归通过。
- tests/profile.cjs：格式白名单、纪录取较高值、无效数据拒绝、写入失败回滚通过。
- tests/mobile.cjs：原生菜单、返回层级、控制方式、生命周期、导入预览/取消与安全区模拟通过。
- assembleRelease / assembleReleaseAndroidTest / lintRelease 成功。
- lint：0 errors，21 warnings（含模板图标、依赖版本等建议）；未将警告描述为全部消除。

限制
- 已验证音效设置持久化及音频恢复代码路径；听感、蓝牙耳机和来电打断需要后续人工体验。
- 不保存正在进行中的航行；保存纪录与设置。卸载前需导出备份。
- 测试后已恢复原始纪录/设置，并重新冷启动核对一致；测试辅助包和临时备份已删除。
- 未在应用商店发布。
