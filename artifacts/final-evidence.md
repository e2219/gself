# 月面拾光 1.9.0 — 3D 改版验证

版本：Android versionCode 17；Three.js r184。网页与 Android 使用同一套离线打包的模型、材质和渲染代码。

## 实现与玩法

星海航行采用实体飞船、陨石、星鲸、空间站及月球网格；月影同行采用有厚度的棋盘、宇航员、月箱与升降门。摄像机保留原来的操作平面，碰撞和关卡规则不变。保留 30 关、中心反向同步操作、后段推箱与按动作推进的回响，不引入扫雷数字。

新增可跳过、可重开的玩法简报，涵盖目标、操作、障碍和规避方法；说明期间暂停模拟，无尽换段不重复弹出。默认静音的解谜事件音效支持真实手势解锁和即时关闭。

激光增加蓄能虚线、汇聚能量、金属发射器、约 7.2 px 主体、白色亮芯与淡外晕，最后 0.15 秒消散。所有层按实际碰撞线段端点裁切，保持通行缺口为空。移除场内“安全间隙”“走绿色缺口”等路线指示；玩法说明保留规则介绍。

设计记录：[设计简报](design-brief.md)、[音效计划](audio-plan.md)。

- 30 关实际浏览器渲染通过；首关真实键盘通关、撤销、重来。全关最大 120 次绘制、46,224 三角形，末关资源为 18 几何体 / 11 纹理。[逐关报告](puzzle-browser-final/report.json)。
- 真实键盘移动、指针操作、失败重试、引导暂停与恢复倒计时、390×844 和 844×390 布局通过。回响点击射线选格通过，静置不会推进时间，每次动作同时推进本体和月影。[输入报告](browser-final/input-report.json)、[运动录像](browser-final/motion/page@532a55a117f0508443f8c8466d5b9102.webm)。

- 激光动态检查覆盖蓄能、发射和消失；逐帧确认渲染段与碰撞段一致、没有路线文字、没有实例溢出。[动态报告](laser-final/phase-report.json)；录像在 `laser-final/motion/`。

## 构建、依赖与限制

`build:web`、`android:sync`、签名 release APK 与测试组件构建通过。3D JS 为 767,250 字节，gzip 201,616 字节；三方 MIT 许可随网页/APK打包。模型为手工程序化实体几何；外部生成服务凭据缺失，未提交付费生成任务。既有音乐授权保留。

实际采用 director、gameplay systems、AAA graphics、UI designer、debug profiler、QA release、audio generator 的工作流与参考资料。3D/image/audio 外部服务均未调用。

依赖审计有 3 个 moderate、0 high、0 critical，位于开发工具的 `@capacitor/cli → xcode → uuid` 链；自动建议涉及 CLI 降级，未强制更换稳定构建工具。此链不打包进入静态游戏或 Android 运行时代码。音效已验证事件、解锁、静音和资源清理，未声称完成扬声器音色的主观听审。
