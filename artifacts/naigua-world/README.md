# 奶蛙世界主题 1.12.0

本次只扩展可选「奶蛙」飞行画面。原版 2D、月夜 3D、30 关回响、碰撞、技能时间轴和共享进度不变。角色以面向镜头的 2.5D 图像轮廓显示，不声称是可绕行观察的完整立体模型。

## 素材来源与分工

- 用户提供的烛台、水下、金色翅膀和火球图片：保留原图像素，以轮廓网格和 UV 排除房间、手机界面、白边。分别用于经典、极光、折跃 Boss 和第二种陨石。
- 用户推荐的 [奶蛙游戏合集](https://milkyfrog.com/games) → [合成大奶蛙（十二月的狼头）](https://yhsome.github.io/BigNaiWa/v1/)：04-lemon.webp 鸡形奶蛙用于探针；07-peach.webp 兔耳踢腿奶蛙用于回旋障碍；09-coconut.webp 祈祷翅膀奶蛙用于阴阳 Boss。保留网站公开透明图像，未复制游戏逻辑。
- [迷失在奶蛙之境](https://www.bilibili.com/video/BV143YA6MEFW/) 中的有脸建筑作为空间站造型参考。空间站、箱子、救援舱、激光嘴、星鲸、传送环、脉冲球、星星、三叉障碍使用重新绘制的透明图集，不将生成素材称为原视频截图。
- 曾检索 Bilibili 视频与公开评论图片；最终不采用黑影、真人手指、裂纹等偏恐怖的候选。
- 先前版本的飞行器、油画背景和用户提供的加速 MP3 继续使用。
