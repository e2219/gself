# 月影同行音效计划

本轮采用本地 Web Audio 合成，不使用外部生成服务；音频服务凭据缺失。沿用 `mooncatch-sound` 白名单设置，默认关闭；不开启背景音乐，不改动飞行模式音轨。

| 事件 | 声音 | 时长 | 触发优先级 |
| --- | --- | --- | --- |
| 成功移动 | 轻柔陶瓷脚步，两档微变音高 | 75 ms | 最低 |
| 推动月箱 | 低频短敲击，加轻微上行尾音 | 140 ms | 高于移动 |
| 门或机关改变 / 换角色 | 两颗清晰音符 | 180 ms | 高于推箱 |
| 无效动作 | 低柔闷声，限频避免长按噪音 | 85 ms | 无移动时 |
| 撤销 / 重放航迹 | 两颗下降音符 | 150 ms | 独立 |
| 通关 | 三颗暖色上行和声音符 | 530 ms | 最高，停止其他尾音 |

同一动作只播放一种最重要的提示。峰值增益低于 0.055，最多同时 8 个振荡器；不使用循环音、不启动游戏计时器。所有振荡器均安排停止并在结束后断开连接。后台、失焦、静音、离开模式时立即停止并挂起音频上下文。只有真实用户指针/键盘操作可以建立或恢复音频上下文。

可见开关位于棋盘顶部；独立网页写入原有设置，嵌入玩法同步父窗口原有声音开关并调用原有存档通知。声音观察游戏状态，不修改回响时间、路线或步数。
